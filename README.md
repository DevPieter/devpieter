## A little about me

I started programming in 2018 after experimenting with Arduino and Raspberry Pi projects. That curiosity soon grew into web development, Discord bots, Minecraft plugins and mods, and full-stack applications. Java and C# are my main languages, and I enjoy working across both front-end and back-end systems.

Away from application code, I run a homelab where I experiment with virtualization, self-hosting, networking, and infrastructure using tools such as Proxmox, OPNsense, WireGuard, and Docker.
